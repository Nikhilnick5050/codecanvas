# CodeCanvas — Nikhil Shinde's Portfolio

A React + Tailwind CSS portfolio with Home, About, Projects, Resume, Contact (Formspree + guest book) and a Supabase guest login.

## Setup

```bash
npm install
cp .env.example .env
# fill in VITE_SUPABASE_URL and VITE_SUPABASE_ANON_KEY
npm run dev
```

Keys are read from environment variables only — never committed to code.
